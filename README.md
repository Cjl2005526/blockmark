# 色块标注（BlockMark）

在手机上把图片里「需要 AI 修改的区域」框出来，导出一张带半透明色块和编号的 PNG，
发给会看图的 AI（GPT-Image、Nano Banana、即梦等）当区域提示。

- 三种形状：矩形、圆形、三角形
- 拖四边单向拉伸，拖四角自由变形（桌面按住 Shift 锁等比）
- **四点透视**：选中后点「变形」，四个角随便拖，能拉成梯形、平行四边形、斜着的任意四边形
- 2～5 个色块，自动编号，删除后编号自动补位
- 撤销 / 重做 / 换色 / 删除
- 导出原图像素的 PNG（超大图自动降到 4096 长边）
- 零依赖、无构建、可离线、可添加到主屏幕

## 跑起来

双击 `start.cmd`，或：

```bash
node server.mjs . 4173
```

终端会打印两个地址：

```
本机：  http://localhost:4173
手机：  http://192.168.x.x:4173
```

手机与电脑连同一个 Wi-Fi，用「手机」那行地址打开即可（也可以直接扫 `qr-lan.png`）。

## 用法

1. 选择图片或拍照
2. 点 `▭ ◯ △` 添加色块；拖四边单向拉伸，拖四角自由变形（桌面按住 Shift 锁等比）
3. 手机上每个控制点会浮在框外、用细线连回真实的边和角 —— 手指按在白点上，不会盖住正在对齐的位置；贴到图片边缘时会自动翻到内侧
4. 要贴合斜着的物体：选中色块 → 点「变形」→ 拖四个角 → 点「完成」；「复位」还原成矩形
5. 点色板换色，`↶ ↷` 撤销重做，`🗑` 删除
6. 点「导出」得到原图像素的 PNG（超大图自动降到 4096 长边）

## 把标注交给 AI

导出图后，把它和一句带编号的说明一起发给 AI。模板：

```
图里有 3 个色块标出的区域，只改这三处，其他保持不变：
1 号（红色矩形）：把天空换成晚霞
2 号（蓝色椭圆）：去掉路人
3 号（绿色三角）：加一只猫
```

几个提高成功率的点：

- **用编号指代区域**，不要只说"上面那块"；编号在图上，模型能对上
- 明确写 **"其他保持不变"**，否则模型容易整张重画
- 一次 3 个以内最稳；区域重叠时模型容易混淆
- 变形过的色块照样能说"1 号"，编号位置跟着包围盒走

## 放到网上（手机随时打开 + 断网可用）

现在这种方式是「电脑当服务器」。想摆脱电脑、像网页一样随时打开，把这个文件夹传到任意**静态托管**就行（纯前端，没有后端、不用数据库）：

**最快：Netlify Drop**
1. 打开 <https://app.netlify.com/drop>
2. 把 `blockmark-site.zip` 解压后的文件夹（或整个项目目录）拖进网页
3. 得到形如 `https://xxxx.netlify.app` 的地址，手机打开即可

**其它同类的**：Cloudflare Pages、Vercel、GitHub Pages、对象存储（OSS/COS）的静态网站模式 —— 都是「上传文件、不加构建命令、根目录即站点」这一套。因为资源全用相对路径，放在子目录（如 `example.github.io/blockmark/`）也能正常工作。

部署之后：

- 手机打开链接 → 分享 → **添加到主屏幕**，以后像 App 一样全屏打开
- 首次打开后资源会被缓存，**断网也能用**（改图、导出都行）
- 更新：重新上传一次即可，Service Worker 是网络优先，下次打开自动拿新版本

> 离线只支持 HTTPS 或 localhost。局域网 `http://192.168.x.x` 只能在线用。

## 测试

```bash
node --test
```

纯几何、状态与撤销、导出尺寸决策都有单元测试，不需要浏览器。

## 端到端自检（可选）

需要本机装了 Chrome。先起一个有调试端口的无头 Chrome：

```powershell
$tmp = Join-Path $env:TEMP "blockmark-cdp"
Start-Process "C:\Program Files\Google\Chrome\Application\chrome.exe" `
  -ArgumentList '--headless=new','--disable-gpu','--remote-debugging-port=9334',"--user-data-dir=$tmp",'--no-first-run','about:blank'
```

然后：

```bash
$env:CDP_PORT=9334
node qa/visual-check.mjs   # 截图 + 拖动/拉伸/导出/撤销的真实事件回放
node qa/photo-check.mjs    # 通过真实的文件选择框载入一张本地照片再导出
node qa/pwa-check.mjs      # Service Worker 与 manifest
```

截图落在 `.superpowers/shots/`（已 gitignore）。

## 开发用的小机关

- `http://localhost:4173/?demo=1` 自动载入一张示例图并放好三个色块，方便调样式
- `window.__blockmark` 暴露了 `store` / `view` / `exportPng()`，可在控制台里玩
- `dev/preview.html` 是不带交互的渲染预览床，用来单独核对色块与编号的视觉效果

## 已知限制

- **iOS 保存**：走系统分享面板（"存储图像"），网页版的先天限制，不是 bug
- **离线 / 安装**：Service Worker 只在 HTTPS 或 localhost 下生效。手机通过局域网 HTTP 打开时功能完全正常，但没有离线和安装能力；部署到任意静态托管（Vercel / Netlify / Cloudflare Pages）后即可获得
- **不自动保存**：刷新或关闭前会弹系统确认，但没有草稿恢复
- **导出只有 PNG**：不做黑白遮罩、不做 JSON 坐标导出
- **没有独立旋转手柄**：要转角度用「变形」拖角实现；变形后的形状不能再用四边单向拉伸以外的仿射操作

## 结构

| 文件 | 职责 |
| --- | --- |
| `src/shapes.js` | 纯几何：创建、移动、八向拉伸、等比、单应变换（四点透视）、形状路径、颜色工具 |
| `src/state.js` | 形状列表、选中、编号、变形模式、撤销重做（最多 50 步） |
| `src/view.js` | 图片等比适配、SVG 形状层、编号徽标、选中框 / 四点角点 |
| `src/gestures.js` | 指针状态机：点选 / 拖动 / 八向拉伸 / 拖角透视 |
| `src/export.js` | 导出尺寸决策、Canvas 绘制（含变形路径）、保存与分享 |
| `src/ui.js` | 工具栏、色板、计数、提示、toast |
| `src/main.js` | 装配、选图、导出流程、PWA 注册 |
| `server.mjs` | 零依赖静态服务器（可被测试直接 import） |
| `sw.js` | 网络优先 + 缓存兜底 |

坐标约定：每个色块的 `x, y, w, h` 都是相对图片显示区域的 0～1 比例值，因此转屏、换设备、导出高分辨率都不会错位。
